# Дизайн-система — Платформа синхронізації конверсій (aControl)

Цей документ визначає візуальну мову, інтерфейсні конвенції та дизайн-токени платформи. Він створений відповідно до обраної концепції **"Precision Hub"** у поєднанні з **Pure Light Mode** (чистим світлим інтерфейсом високої чіткості).

---

## 1. Основна концепція: "Precision Hub" (Світла тема)

Дизайн платформи надихається класичними інженерними кресленнями, таблицями даних та точними вимірювальними приладами. Він відкидає зайві тіні та градієнти на користь чіткої сітки, тонких роздільних ліній та яскравих функціональних кольорових акцентів.

### Основні принципи:
1. **Чітка сітка та межі:** Картки та блоки розділені тонкими лініями (`border: 1px solid #E2E8F0`). Тіні майже не використовуються.
2. **Контраст та читабельність:** Глибокий чорний текст на чистому білому/світло-сірому фоні.
3. **Енергія через акценти:** Спокійне світле тло доповнюється технологічним синім (процес синхронізації) та теплим бурштиновим (цінність конверсій, цифри).
4. **Мікро-анімація зв'язків:** Рух даних передається плавними переходами та пульсуючими точками на лініях зв'язку.

## 2. Дизайн-токени (CSS змінні)

Всі кольори мають чітке функціональне призначення.

```css
:root {
  /* Базові кольори фону */
  --bg-page: #FCFCFC;        /* Світлий папір з ледь теплим відтінком */
  --bg-card: #FFFFFF;        /* Чистий білий для карток та кабінету */
  --bg-secondary: #F8FAFC;   /* Світло-сірий для таблиць, сайдбарів */

  /* Текст */
  --text-primary: #0F172A;   /* Глибокий темно-синій/чорний для заголовків та основного тексту */
  --text-secondary: #475569; /* Приглушений сірий для підписів та описових елементів */
  --text-muted: #94A3B8;     /* Слабкий сірий для плейсхолдерів, іконок */

  /* Контури та роздільники */
  --border: #E2E8F0;         /* Тонкі лінії сітки кабінету */
  --border-active: #CBD5E1;  /* Акцентний контур для активних полів */

  /* Акценти та Сигнали */
  --accent-blue: #2563EB;    /* Сигнал синхронізації: активні з'єднання, кнопки, посилання */
  --accent-amber: #D97706;   /* Енергія конверсій: сумарна цінність, ключові цифри */
  
  /* Статуси */
  --status-success: #16A34A; /* Активна підписка, успішна синхронізація */
  --status-warning: #EA580C; /* Попередження (підписка на паузі) */
  --status-danger: #DC2626;  /* Помилка, підписка зупинена (Suspended) */
}
```

## 3. Типографіка

Шрифтова схема підкреслює технічний характер платформи.

| Роль | Шрифт (Google Fonts) | Вага (Weight) | Специфіка використання |
| :--- | :--- | :--- | :--- |
| **Display / Headers** | `Space Grotesk` | `500` (Medium), `600` (Semi-Bold) | Великі метрики, заголовки секцій, назви кабінетів. Має геометричні кутасті форми. |
| **Body / UI** | `Inter` | `400` (Regular), `500` (Medium) | Тексти інструкцій, підписи, елементи форм, меню. Максимальна читабельність. |
| **Mono / Technical** | `JetBrains Mono` | `400` (Regular), `500` (Medium) | Дані API, API-ключі, код Apps Script, таблиці конверсій. |

## 4. Фірмовий елемент (Signature)

### **Анімована схема "Data Flow Visualizer"**
У верхній частині особистого кабінету розміщується інтерактивна панель синхронізації:
* **Ліва сторона:** Вузли джерел даних (CRM, Телефонія, Месенджери) з іконками.
* **Центр:** Вузол обробника `webguide` (логотип із зеленим/синім круглим індикатором статусу).
* **Права сторона:** Рекламні кабінети (Google Ads, Meta Ads).
* **Ефект:** Тонкі лінії з'єднують джерела з центром і кабінетами. При надходженні конверсії лінією пробігає світлова крапка (CSS dash-offset анімація), символізуючи успішну передачу конверсії в реальному часі.
* **Призначення:** Відразу показує користувачеві, що система "жива", налаштована правильно та активно синхронізує дані.

## 6. База знань (Knowledge Base)

Розділ інструкцій також підтримує естетику інженерного посібника:
* Дворівнева навігація: лівий сайдбар з категоріями (CRM, Телефонія, Рекламні сервіси, Apps Script), правий контентний блок.
* Використання чітких кроків з іконками `[1]`, `[2]` замість складного форматування.
* Для коду Apps Script використовується блок копіювання в один клік з моноширинним шрифтом та чіткими коментарями.

## 7. Валідація дизайну (Self-Critique Checklist)

Перед здачею будь-якого інтерфейсного компоненту, перевіряти його за цим списком:
- [ ] Чи відповідає палітра кольорів схемі (немає ad-hoc кольорів поза CSS змінними)?
- [ ] Чи використано шрифтову пару `Space Grotesk` (для заголовків та цифр) + `Inter` (для тексту)?
- [ ] Чи збережено технічний стиль (відсутність заокруглень великого радіуса, відсутність розмитих фонових тіней)?
- [ ] Чи є інтерфейс повністю адаптивним на мобільних пристроях?
- [ ] Чи відповідають тексти спокійному тону бренду без знаків оклику (BC-BRAND-01)?
