            Issue Summary

            Gitlab SaaS integration with Rovo Dev is not supported natively.

            Steps to Reproduce

            Customer requires native GitLab SaaS (gitlab.com) integration with Rovo Dev to enable AI-assisted code generation, code review, and autonomous agent workflows directly within their GitLab-hosted repositories.

            Expected Results

            The customers wants to uses GitLab SaaS as their primary source code management platform. They are interested in adopting Rovo Dev for AI-powered development workflows but are currently blocked due to the lack of native GitLab SaaS support. Specifically, they need:

            • Rovo Dev CLI to connect to and operate on GitLab SaaS repositories (clone, branch, commit, push, create merge requests)
            • Rovo Dev Code Reviewer to run automated AI code reviews on GitLab merge requests
            • Rovo Dev Agents in Jira to reference and act on code hosted in GitLab repositories
            • IDE integration (VS Code / JetBrains) with Rovo Dev that works seamlessly with GitLab-hosted projects

            Actual Results

            Currently, activate code reviews in your repository is only supported in Bitbucket and GitHub but not for Gitlab.

            Workaround

            Currently there is no known workaround for this behavior. A workaround will be added here when available
