## 1. Setup and Project Configuration

- [ ] 1.1 Додати необхідні залежності (`drizzle-orm`, `@neondatabase/serverless` або `pg`) та dev-залежності (`drizzle-kit`, `@types/pg`) у `package.json`.
- [ ] 1.2 Створити файл конфігурації `drizzle.config.ts` у корені проекту для налаштування `drizzle-kit`.
- [ ] 1.3 Оновити `.env.example` та локальний `.env` змінними `DATABASE_URL` та `ENCRYPTION_KEY` (32-байтовий ключ у hex-форматі).

## 2. Ініціалізація клієнта бази даних

- [ ] 2.1 Реалізувати файл `db/index.ts` для підключення до бази даних з урахуванням специфіки Serverless (лінива ініціалізація та перевикористання з'єднання).

## 3. Опис схем таблиць Drizzle ORM

- [ ] 3.1 Створити файл `db/schema/users.ts` та визначити таблицю `users` з полями для Telegram-бота (telegram_id як bigint), CRM-інтеграції, телефонії та унікального api_key_hash.
- [ ] 3.2 Створити файл `db/schema/magic_links.ts` та визначити таблицю `magic_links` для короткоживучих токенів входу.
- [ ] 3.3 Створити файл `db/schema/sessions.ts` та визначити таблицю `sessions` з токенами активних сесій.
- [ ] 3.4 Створити файл `db/schema/subscriptions.ts` та визначити таблицю `subscriptions` із статусами підписки, платіжними токенами monobank, а також полями ретраїв списань та invoice_id.
- [ ] 3.5 Створити файл `db/schema/conversions.ts` та визначити таблицю `conversions` для збереження записів конверсій з індексами для аналітики та автоматичного очищення.
- [ ] 3.6 Створити файл `db/schema/index.ts` для об'єднання та експорту всіх таблиць схеми.

## 4. Утиліти шифрування та дешифрування

- [ ] 4.1 Реалізувати модуль шифрування `lib/crypto.ts` на базі алгоритму AES-256-GCM з використанням вбудованого модуля `crypto` в Node.js.
- [ ] 4.2 Створити unit-тести або тимчасовий тестовий скрипт для перевірки коректності шифрування та дешифрування даних.

## 5. Генерація міграцій та перевірка

- [ ] 5.1 Запустити генерацію міграцій (`npx drizzle-kit generate`) та перевірити згенеровані SQL-файли у директорії `db/migrations`.
- [ ] 5.2 Перевірити збірку проекту (`npm run build` або компиляцію TypeScript) на відсутність помилок типізації схеми та підключення бази даних.
