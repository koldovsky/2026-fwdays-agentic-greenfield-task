## Why

Налаштування базової бази даних та ORM є критично важливим першим кроком у розробці платформи, оскільки всі інші можливості (авторизація, білінг, прийом конверсій та аналітика) безпосередньо залежать від наявності структурованого та безпечного сховища даних. Надійна схема бази даних та інструменти шифрування чутливих даних закладають основу для відповідності технічним та нефункціональним вимогам проекту.

## What Changes

Впровадження цієї можливості включає такі зміни:
- Ініціалізація та налаштування Drizzle ORM для роботи з PostgreSQL (Neon/Supabase).
- Визначення схеми бази даних (таблиці для користувачів, сесій, підписок, конверсій та інтеграцій).
- Реалізація модуля шифрування/дешифрування чутливих даних користувача (паролі CRM, API-ключі телефонії) з використанням алгоритму AES-256-GCM.
- Налаштування підключення до бази даних у середовищі Next.js з урахуванням безкоштовних лімітів (Serverless-оптимізація).

## Capabilities

- `core-database`: Базова схема даних, підключення через Drizzle ORM до PostgreSQL, механізми шифрування AES-256-GCM для чутливих облікових даних користувачів.

## Impact

- **Нові залежності**: додавання `drizzle-orm`, `pg` (або `@neondatabase/serverless`), `dotenv` та відповідних `devDependencies` (`drizzle-kit`, `@types/pg`).
- **Структура проекту**: створення файлів конфігурації `drizzle.config.ts`, ініціалізація модуля бази даних у `db/` та схем у `db/schema/`.
- **Безпека**: створення сервісу шифрування у `lib/crypto.ts`, що потребуватиме додавання `ENCRYPTION_KEY` у змінні середовища `.env`.
