# Capacity View — Delta Spec

Дельта-специфікація capability `capacity-view` (FR-CAP-01..05) на Recharts
(TC-STACK-04).

## ADDED Requirements

### Requirement: Two-level Load Histogram

Система SHALL показувати гістограму завантаженості РЦ у двох рівнях: агреговано
по групах РЦ (ГРЦ) і розгорнуто по окремих РЦ, з перемиканням між ними
(FR-CAP-01). Вісь Y SHALL відображати % від потужності з межею 100 %, а
перевантаження (> 100 %) SHALL підсвічуватися червоним (FR-CAP-02).

#### Scenario: Load percent aggregates by RC and by RC-group

- **GIVEN** ГРЦ-1 з РЦ-1 і РЦ-2, фонд 480 хв/день кожен, за один робочий день
  РЦ-1 використано 240 хв, РЦ-2 — 480 хв
- **WHEN** будується гістограма
- **THEN** на рівні РЦ: РЦ-1 = 50 %, РЦ-2 = 100 %
- **AND** на рівні ГРЦ: ГРЦ-1 = 75 %

### Requirement: Horizon-adaptive Time Axis

Система SHALL адаптувати одиницю осі X до горизонту планування: дні для ~3
тижнів, тижні для ~3 місяців, місяці для року (FR-CAP-03).

#### Scenario: Axis unit follows the horizon length

- **WHEN** горизонт становить приблизно 3 тижні / 3 місяці / рік
- **THEN** одиниця осі X дорівнює день / тиждень / місяць відповідно

### Requirement: Hover Tooltip with Operations

Система SHALL при наведенні на стовпець показувати список операцій цього слоту з
трудомісткістю (хв) і номером замовлення (FR-CAP-04).

#### Scenario: Tooltip lists the slot's operations

- **WHEN** користувач наводить на стовпець завантаження
- **THEN** зʼявляється список операцій слоту з `opName`, `orderId` і тривалістю

### Requirement: Capacity KPI Row

Система SHALL показувати над гістограмою KPI-рядок: середню завантаженість по
всіх РЦ, кількість перевантажених слотів і кількість РЦ з нульовим завантаженням
(простій) (FR-CAP-05).

#### Scenario: KPIs reflect average load, overload, and idle RCs

- **GIVEN** РЦ-1 завантажено 480/480, РЦ-2 — 600/480 (перевантаження), РЦ-3 — 0
- **WHEN** обчислюються KPI
- **THEN** середня завантаженість ≈ 75 %, перевантажених слотів = 1, РЦ з нульовим
  завантаженням = 1
