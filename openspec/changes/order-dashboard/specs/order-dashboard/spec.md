# Order Dashboard — Delta Spec

Дельта-специфікація capability `order-dashboard` (FR-ORD-01..05).

## ADDED Requirements

### Requirement: Orders Table with Derived Status

Система SHALL показувати таблицю замовлень із номером, виробом, кількістю, датою
здачі, розрахованою датою готовності, відхиленням у робочих днях і статусом
(FR-ORD-01). Статус SHALL визначатися так: «Заблоковано матеріалом», якщо
замовлення у списку заблокованих дефіцитом; інакше «Запізнення», якщо відхилення
> 0; інакше «Під загрозою», якщо слак до дедлайну ≤ 2 робочі дні; інакше «В
графіку» (FR-ORD-02).

#### Scenario: Each order gets the correct status

- **GIVEN** замовлення з великим слаком, зі слаком ≤ 2 дні, із запізненням і
  заблоковане дефіцитом
- **WHEN** будується таблиця
- **THEN** їм присвоєно «В графіку», «Під загрозою», «Запізнення» і «Заблоковано
  матеріалом» відповідно

### Requirement: Default Sort by Largest Delay

Система SHALL за замовчуванням сортувати замовлення за відхиленням спадно —
найбільше запізнення зверху (FR-ORD-04).

#### Scenario: Most-delayed orders appear first

- **GIVEN** замовлення з відхиленнями 0, 4, 2
- **WHEN** таблиця сортується за замовчуванням
- **THEN** порядок відхилень зверху вниз — 4, 2, 0

### Requirement: Summary Row

Система SHALL показувати підсумковий рядок: загальну кількість замовлень і
кількості в графіку, під загрозою та із запізненням (FR-ORD-05).

#### Scenario: Summary counts orders by status

- **GIVEN** набір замовлень різних статусів
- **WHEN** обчислюється підсумок
- **THEN** повертаються `total` і кількості по кожному статусу

### Requirement: Expandable BOM Tree per Order

Система SHALL за кліком на рядок замовлення розгортати дерево BOM із плановими
датами (старт/фініш) і статусом кожного вузла (FR-ORD-03).

#### Scenario: Row expands into a dated BOM tree

- **GIVEN** замовлення з операціями на вузлах `O1#A`, `O1#A/B`, `O1#A/B/D`
- **WHEN** будується дерево BOM замовлення
- **THEN** повертається корінь `O1#A` з нащадком `O1#A/B`, у якого нащадок
  `O1#A/B/D`
- **AND** для кожного вузла плановий старт = найраніший старт його операцій,
  фініш = найпізніший кінець, а статус = найгірший статус операцій
