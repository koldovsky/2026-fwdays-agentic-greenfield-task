# Specs: dashboard

Вимоги з PRD v0.3 (capability `dashboard`, FR-DASH-01..02). ID для трасування.

- **FR-DASH-01** Головний екран після імпорту показує: зведення замовлень
  (статуси), топ-5 найбільших запізнень, критичні дефіцити матеріалів,
  перевантажені РЦ.
- **FR-DASH-02** З кожного блоку дашборду є перехід до відповідного детального
  розділу (Гантт, таблиця замовлень, матеріали, завантаженість).

## Сценарії тестування

### Сценарій A — Статуси і топ-5 запізнень
```
Вхід: замовлення з delayDays 5, 3, 0, 2, 7, 1 (+ due/ready), дефіцити, capacity
Очікування (buildOverview):
  statusCounts містить кількості по статусах
  topDelays = 5 замовлень із найбільшим delayDays спадно, лише delay > 0
```

### Сценарій B — Критичні дефіцити
```
Вхід: дефіцит M (earliestCoverDate null) + N (дата)
Очікування: criticalDeficits = [M]  (N — покривний, не критичний)
```

### Сценарій C — Перевантажені РЦ
```
Вхід: capacity зі слотами loadPct 120, 80, 150, 100
Очікування: overloadedCells = слоти 150 і 120 (тільки > 100, спадно)
```
