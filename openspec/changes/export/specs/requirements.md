# Specs: export

Вимоги з PRD v0.3 (capability `export`, FR-EXP-01..05). ID для трасування.

- **FR-EXP-01** Експорт розкладу операцій у Excel: замовлення, виріб, вузол BOM,
  ГРЦ, РЦ, операція, початок, кінець (дата+час), тривалість (хв), статус.
- **FR-EXP-02** Експорт таблиці дефіциту матеріалів у Excel.
- **FR-EXP-03** Експорт зведення по замовленнях у Excel.
- **FR-EXP-04** Збереження Гантта у PDF із поточними фільтрами і масштабом.
- **FR-EXP-05** Структура колонок Excel узгоджена з форматом вивантаження з 1С
  (для зворотного завантаження).

## Технічне

- **TC-STACK-05** Парсинг/запис Excel: SheetJS — виключно на клієнті.

## Сценарії тестування

### Сценарій A — Розклад операцій
```
Вхід: операція O1/виріб A, вузол D, ГРЦ-1, РЦ-1, «Оп», 60 хв, статус ok
Очікування (buildOperationsSheet):
  headers = [Замовлення, Виріб, Вузол BOM, ГРЦ, РЦ, Операція, Початок, Кінець,
             Тривалість (хв), Статус]
  рядок = [O1, A, D, ГРЦ-1, РЦ-1, Оп, '2026-01-05 00:00', '2026-01-05 01:00',
           60, 'В графіку']
```

### Сценарій B — Дефіцити
```
Вхід: критичний дефіцит M (earliestCoverDate null) + покривний N (дата)
Очікування (buildDeficitsSheet):
  рядок M: дата закриття = 'критичний'
  рядок N: дата закриття = '2026-01-15'
```

### Сценарій C — Зведення по замовленнях
```
Вхід: OrderRow {O1, виріб A, к-сть 5, due, ready, delay 0, on-schedule}
Очікування (buildOrderSummarySheet):
  рядок = [O1, A, 5, дата здачі, дата готовності, 0, 'В графіку']
```
