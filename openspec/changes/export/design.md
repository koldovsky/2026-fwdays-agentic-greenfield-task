# Design: export

## Розподіл: чиста побудова рядків ↔ запис/друк

```
lib/export/
  types.ts   ← ExportCell, SheetData
  build.ts   ← buildOperationsSheet, buildDeficitsSheet, buildOrderSummarySheet
  index.ts   ← публічний API
src/
  export/xlsx.ts        ← writeSheet(SheetData, filename) — SheetJS запис (клієнт)
  components/ExportPanel.tsx  ← кнопки експорту + друк Гантта
  components/print.css   ← print-стилі, що ізолюють .gantt (FR-EXP-04)
```

## Модель

```typescript
type ExportCell = string | number
interface SheetData {
  name: string        // назва аркуша
  headers: string[]   // рядок заголовків
  rows: ExportCell[][] // дані (без заголовка)
}
```

Запис: `aoa = [headers, ...rows]` → `XLSX.utils.aoa_to_sheet` → `writeFile`.

## Excel-експорти (чисті функції)

### Розклад операцій (FR-EXP-01)
Колонки: Замовлення, Виріб, Вузол BOM, ГРЦ, РЦ, Операція, Початок, Кінець,
Тривалість (хв), Статус. «Виріб» — номенклатура готового виробу замовлення
(з `orders`); «Вузол BOM» — номенклатура вузла (`op.nomenclatureId`). Дати —
`YYYY-MM-DD HH:mm` (UTC). Детермінований порядок за початком, потім вузлом і opNo.

### Дефіцити (FR-EXP-02)
Колонки: Матеріал, Брутто-потреба, Залишок, План надходжень, Нетто-дефіцит,
Дата закриття, Заблоковані замовлення. Дата закриття `null` → «критичний».

### Зведення по замовленнях (FR-EXP-03)
Колонки: Замовлення, Виріб, Кількість, Дата здачі, Дата готовності, Відхилення
(роб. дн.), Статус. Джерело — `OrderRow[]` із `lib/dashboard` (статуси вже
обчислені).

## Сумісність з 1С (FR-EXP-05)

Заголовки — українська термінологія, узгоджена з псевдонімами колонок імпорту
(`Замовлення`, `Номенклатура/Виріб`, `ГРЦ`, `РЦ`, `Кількість`, `Дата` тощо), тому
файли читаються тими самими парсерами й придатні для зворотного завантаження.

## Гантт у PDF (FR-EXP-04)

Кнопка → `window.print()`. `print.css` (@media print) ховає все, крім `.gantt`,
тому друкується поточний Гантт із застосованими фільтрами й масштабом (вони вже
у DOM). Користувач зберігає як PDF діалогом друку браузера.

## Обмеження MVP

| Обмеження | Рішення |
|---|---|
| PDF лише через друк браузера | Достатньо для MVP; макет = поточний вигляд Гантта |
| Статуси у Excel — українські мітки | Читабельніше; коди статусів можна додати колонкою за потреби |
