## Context

Поточний стан головної сторінки (`app/page.tsx`) є стандартним шаблоном Next.js. Платформа не має публічної інформаційної сторінки, тарифної сітки та відкритої бази знань, що обмежує можливість ознайомлення з сервісом до реєстрації.

## Goals / Non-Goals

**Goals:**
- Заміна `app/page.tsx` на сучасний публічний лендинг з описом переваг, тарифів ($10.99/міс, $120/рік) та інтерактивним FAQ.
- Створення роуту `app/kb/page.tsx` з покроковими інструкціями для інтеграції GA4, Google Ads, GCP (для `auto@acontrol.pro`) та Binotel, доступними публічно без авторизації.
- Дотримання вимог стилю Precision Hub та Pure Light Mode (світла колірна гама з акцентами).
- Дотримання вимог приватності (без аналітичних трекерів та зайвих cookies).

**Non-Goals:**
- Створення додаткової адмін-панелі для редагування статей бази знань (статті фіксуються в коді як статичний контент).
- Впровадження складного пошуку по базі знань.

## Decisions

### 1. Структура публічного лендингу (`app/page.tsx`)
- **Рішення**: Реалізувати лендинг як серверний компонент, що містить секцію Hero, опис інтеграцій, тарифну сітку та блок FAQ.
- **Обґрунтування**: Швидке завантаження (SSR) та відсутність потреби в складному стейті для більшої частини контенту. Для акордеону FAQ буде використано простий клієнтський підкомпонент.

### 2. Публічна база знань (`app/kb/page.tsx`)
- **Рішення**: Створити окрему публічну сторінку `/kb` з навігаційним меню (або табами) зліва та детальним описом налаштувань справа, а також підтримкою query-параметра `tab` для вибору активного розділу інструкції.
- **Обґрунтування**: Дозволяє надати чистий і сфокусований інтерфейс для читання документації, куди можна легко посилатися з Telegram-бота за допомогою прямих лінків на конкретний розділ (наприклад, `/kb?tab=gcp`). Контент інструкцій буде дублювати та розширювати поточний `app/dashboard/InstructionsTab.tsx`.

### 3. Стилізація та дизайн-система
- **Рішення**: Використання Tailwind CSS v4 та наявних змінних кольорів (`--bg-page`, `--text-primary`, `--accent-blue`, `--accent-amber`).
- **Обґрунтування**: Повна сумісність з існуючим дизайном кабінету та забезпечення преміального вигляду Precision Hub.

### 4. Відсутність сторонніх трекерів
- **Рішення**: Утриматися від встановлення будь-яких зовнішніх скриптів аналітики (Google Analytics, GTM, Hotjar) на публічних сторінках.
- **Обґрунтування**: Відповідність вимозі `BC-PRIVACY-01` щодо захисту приватності користувачів.

## Risks / Trade-offs

- **[Risk] Дублювання контенту інструкцій між кабінетом та публічним `/kb`** → *Mitigation*: Винести контент інструкцій в окремий файл констант або спільний компонент, який буде імпортуватися і в `app/dashboard/InstructionsTab.tsx`, і в `app/kb/page.tsx`.
