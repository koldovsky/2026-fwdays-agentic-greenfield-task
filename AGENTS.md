# Agentic Engineering Homework Repository

## Repository Purpose

This fork contains the Email Shadow Panel course project under `/email-shadow-panel`.

Preserve the upstream homework repository structure, `.coderabbit.yaml`, pull-request template, and course documentation.

## Working Scope

Unless a task explicitly says otherwise, application work belongs inside `/email-shadow-panel`.

Do not edit unrelated course files.

## Process Requirements

The project must preserve visible evidence of:

- context engineering;
- specifications written before implementation;
- implementation and verification loops;
- tests or evals;
- maker/checker separation;
- CodeRabbit review and remediation;
- actual evidence rather than unsupported claims.

Do not fabricate verification, review, benchmark, deployment, screenshot, or test results.

## Security

Never commit:

- `.env` files or `.vercel`;
- provider cookies, XSRF tokens, capability tokens, or session capsules;
- active generated inbox addresses;
- personal sender addresses or message content;
- local databases;
- raw provider captures or traces.
