Honest provenance line — states the effective date and that the figure is the official NBU rate. When `stale` (weekend / holiday) it says "Курс за …" in brass rather than pretending the number is today's.

```jsx
<AsOfBadge date="29.06.2026" />
<AsOfBadge date="27.06.2026" stale />
```

Props: `date` (mono), `stale`, `source` (default `НБУ`).
