A small status pill keyed to brand + trend semantics. Default is a soft tint; `solid` fills it. Set `mono` when the content is a number.

```jsx
<Badge tone="brand">Офіційний</Badge>
<Badge tone="up" mono>+1.2%</Badge>
<Badge tone="down" mono>-0.4%</Badge>
<Badge tone="flat">Без змін</Badge>
<Badge tone="accent" solid>НБУ</Badge>
```

Tones: `brand`, `up`, `down`, `flat`, `accent`, `neutral`. Props: `solid`, `mono`.
