The brand's primary action control — treasury-green fill, lightly rounded, a gentle press (scales to 0.99). Use for any commit action; pair with an icon for clarity.

```jsx
<Button variant="primary" iconLeft="arrow-right-left">Поміняти напрям</Button>
<Button variant="secondary">Показати всі валюти</Button>
<Button variant="ghost" size="sm" iconRight="chevron-right">Деталі</Button>
```

Variants: `primary` (green fill), `secondary` (green tint), `outline`, `ghost`. Sizes: `sm` / `md` / `lg`. Props: `iconLeft`, `iconRight` (Lucide names), `fullWidth`, `disabled`.
