Thin wrapper over [Lucide](https://lucide.dev) at the brand's calm 1.75 stroke. Requires the Lucide UMD script loaded globally. Colour follows `currentColor`.

```jsx
<Icon name="trending-up" size={18} />
<Icon name="arrow-right-left" label="Поміняти напрям" />
```

Props: `name` (Lucide id), `size` (px, default 20), `stroke` (default 1.75), `label` (accessible name; omit to hide from AT).
