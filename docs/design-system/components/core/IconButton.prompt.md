A square, icon-only control. Always pass `label` (used for both the accessible name and the tooltip). Presses to 0.94 scale.

```jsx
<IconButton icon="moon" label="Нічна тема" variant="soft" />
<IconButton icon="arrow-right-left" label="Поміняти напрям" variant="outline" />
```

Variants: `outline`, `soft` (green tint), `ghost`. Sizes: `sm` / `md` / `lg`.
