Labelled text input.

```jsx
<Input label="Name" defaultValue="Marina Sokolova" />
<Input label="Role" hint="(optional)" fill="paper" />
```

1px `--line-strong` border, 8px radius, 14px Inter. Use `fill="paper"` for inputs sitting inside a white card (so the field reads against the card), `white` on the paper app background. Labels are 13px muted, sentence case.
