# Bookshelf — Product Brief

_Дата: 2026-06-27_

## Що це

Локальний застосунок для нотаток по прочитаних книжках. Прочитав книжку →
виписав нотатки (цитата + рефлексія) → зв'язав із вже наявними книжками/нотатками
→ виділив кольором-хайлайтером → поставив оцінку → написав самарі. Кожна книжка
має свою сторінку, головна сторінка індексує колекцію у «полиці» за тегами.

UI — англійською, у візуальній мові дизайн-системи `docs/design-system/`
(тепла «паперова» палітра, літературний serif, хайлайтери для нотаток).

## Для кого

Один користувач (власник), один пристрій. Це особистий інструмент, а не
сервіс — тому без реєстрації, авторизації, акаунтів і хмари.

## Навіщо

- Зберігати думки про книжки в одному місці у власному, не-замкненому форматі.
- Бачити зв'язки між книжками («ця ідея перегукується з Книжкою X»).
- Швидко переглядати колекцію, оцінки й самарі.

## Ключові цінності продукту

1. **Дані належать користувачу.** Усе зберігається як звичайні Markdown-файли
   на диску. Жодного vendor lock-in: файли читабельні, бекапляться, працюють із
   git/Obsidian навіть без застосунку.
2. **Зв'язність.** Нотатки й книжки утворюють граф через wiki-посилання та
   беклінки.
3. **Простота.** Мінімум залежностей, нуль інфраструктури, запуск локально.

## Платформа й технології

- **Next.js (App Router)** — фронтенд і серверна логіка в одному застосунку.
- **Сховище:** локальна файлова система (Markdown + YAML frontmatter).
- **UI:** поверх дизайн-системи `docs/design-system/` (компоненти + токени), English.
- **Запуск:** локально на машині користувача (`next dev` / локальний `next start`).

## Свідомо поза скоупом (YAGNI)

Авторизація, мультикористувачі, хмара/синхронізація, повнотекстовий пошук,
виділення фрагментів тексту всередині нотатки, версіонування. Можуть бути
розглянуті пізніше, але не входять у перший реліз.

## Критерії успіху

- Можу додати книжку з усіма полями та зберегти її як `.md` на диску.
- Можу писати кольорові нотатки-картки й ставити посилання на інші книжки/нотатки.
- На сторінці книжки видно беклінки («сюди посилаються»).
- Головна сторінка групує книжки за тегами з обкладинками й оцінками.
- Усі дані лишаються читабельними файлами, які можна відкрити без застосунку.
