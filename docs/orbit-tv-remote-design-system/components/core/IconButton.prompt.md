Circular neumorphic icon-only button — the workhorse of the remote control screen.

```jsx
<IconButton icon="keyboard_arrow_up" />
<IconButton icon="power_settings_new" tone="accent" size="lg" />
<IconButton icon="volume_off" active />
```

Notable: `active` locks the inset/pressed look for toggled state (e.g. muted). `tone="danger"` for destructive actions like removing a paired TV.
