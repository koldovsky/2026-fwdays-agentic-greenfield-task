If creating visual artifacts (slides, mocks, throwaway prototypes, etc), copy assets out and create static HTML files for the user to view. If working on production code, you can copy assets and read the rules here to become an expert in designing with this brand.
If the user invokes this skill without any other guidance, ask them what they want to build or design, ask some questions, and act as an expert designer who outputs HTML artifacts _or_ production code, depending on the need.

Key facts to hold onto:
- Style: Neumorphism (soft UI) — one flat surface color, all depth via paired raised/inset drop shadows. Never add borders, gradients-on-backgrounds, or flat-fill "cards" with a different color than the page.
- Typeface: Montserrat only, everywhere.
- Icons: Material Symbols Rounded only — never emoji, never hand-drawn SVGs.
- No logo exists for this brand — never invent one; render the name in Montserrat type instead.
- Accent color (warm orange) is reserved for exactly one primary action per screen plus live/active states.
