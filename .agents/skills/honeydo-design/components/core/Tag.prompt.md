Small color-dotted label for categorizing time entries.

```jsx
<Tag color="amber">Design</Tag>
<Tag color="green">Admin</Tag>
<Tag color="#5B8DEF" size="sm">Meetings</Tag>
```

`color` is a preset (`amber, gold, green, clay, plum, teal, blue, brown`) or any CSS color. `TAG_COLORS` exports the preset map. For a selectable filter pill use `FilterChip` instead.
