Circular icon-only button for navigation, toolbar, and quick "continue" actions.

```jsx
<IconButton variant="accent" label="Start timer"><Play /></IconButton>
<IconButton variant="soft" label="More"><MoreHorizontal /></IconButton>
```

Variants: `soft` (translucent fill), `accent` (amber), `outline`, `plain`. `size` is the diameter in px (default 40; keep ≥44 for primary touch targets). Always pass `label` for accessibility.
