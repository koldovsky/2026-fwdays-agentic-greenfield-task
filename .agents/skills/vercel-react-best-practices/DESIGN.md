# DESIGN.md — APS Планувальник РЦ

## Візуальна ідентичність
- Темна тема (виробниче середовище, часто відкрите на другому моніторі)
- Акцент: #00C896 (зелений = в нормі), #F5A623 (жовтий = ризик), #E74C3C (червоний = проблема)
- Шрифт: системний sans-serif, моноширинний для кодів операцій і РЦ

## Layout
- Верхня панель: горизонт планування + кнопка "Запустити планування"
- Ліва колонка (30%): дерево замовлень / BOM
- Центр (70%): Гантт або гістограма завантаженості (табами)
- Нижня панель: дефіцити матеріалів + KPI-рядок

## Ключові UX-рішення
- Drag-and-drop на Гантті → негайний перерахунок залежних операцій
- Колір смуги = статус (синій/жовтий/червоний/сірий)
- Фільтр за ГРЦ, замовленням, статусом — завжди видимий
- Імпорт: drag-and-drop зони для кожної таблиці окремо

## Технічний стек (TC з PRD)
- React 18 + TypeScript strict + Vite
- Гантт: dhtmlx-gantt (Community Edition)
- Графіки: Recharts
- Excel: SheetJS (xlsx)
- Стан: Zustand
- Тести: Vitest
